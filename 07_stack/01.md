# 01.asm
The program starts by copying the values 100 and 200 into rax and rbx respectively.
Using gdb tui,I debug the code line by line looking at how the registers respond especially *rsp,rax,rbx*
The observation was each push decremented the stack pointer value since it grows downward in terms of memory
## Before Push
Pointer address was at:0x7fffffffde70
## After Push
Pointer Address was at:0x7fffffffde60

I also noteed that the push did not mean cutting and moving the values.It was copying the values from **rax** into the memory address pointed to by **rsp**

Executing the pop instruction yields an increment in the rsp value
