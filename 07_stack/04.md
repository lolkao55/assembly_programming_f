# 04.asm — 32-bit stack frame

This program calls `work`, uses the stack to save the caller's frame pointer and reserve two local-variable slots, then restores the frame and exits. In 32-bit mode, `ESP` is the stack pointer and each pushed value or return address occupies 4 bytes. The stack grows toward lower addresses.


## Execution and stack changes

| Instruction(s) | Effect on the stack | GDB observation |
|---|---|---|
| At `_start` | No stack operation yet. | `ESP = 0xffffcfa0` before the call. |
| `call work` | Pushes the address of the next instruction (`0x08049005`) and jumps to `work`; `ESP` decreases by 4. | `ESP: 0xffffcfa0 -> 0xffffcf9c`; the return address is at the top. |
| `push ebp` | Saves the caller's `EBP`; `ESP` decreases by 4. | `ESP: 0xffffcf9c -> 0xffffcf98`. In this run the saved `EBP` value was `0`. |
| `mov ebp, esp` | Does not change the stack. Sets `EBP` to anchor this function's stack frame. | `EBP = 0xffffcf98`. |
| `sub esp, 8` | Reserves 8 bytes for two 4-byte local values; `ESP` decreases by 8. | `ESP: 0xffffcf98 -> 0xffffcf90`. |
| Store `100` at `[ebp - 4]` and `200` at `[ebp - 8]` | Writes the locals into the reserved slots; `ESP` does not change. | GDB showed `0x64` (100) at `EBP-4` and `0xc8` (200) at `EBP-8`. The second local is at the lower address. |
| Load the locals into `EAX` and `EBX`; `nop` | Reads the values into registers; does not change the stack. | `EAX = 100`, `EBX = 200`; `ESP` remains `0xffffcf90`. |
| `mov esp, ebp` | Releases the local-variable area by moving `ESP` back to the saved-frame-pointer slot. | `ESP: 0xffffcf90 -> 0xffffcf98`. |
| `pop ebp` | Restores the caller's saved `EBP`; `ESP` increases by 4. | `EBP` is restored to `0`; `ESP: 0xffffcf98 -> 0xffffcf9c`. |
| `ret` | Pops the saved return address into the instruction pointer; `ESP` increases by 4 and execution resumes after `call work`. | `ESP: 0xffffcf9c -> 0xffffcfa0`; execution returns to `0x08049005`. |
| Exit syscall | `EAX` is set to `1`, `EBX` to `0`, then `int 0x80` exits. These instructions do not push or pop stack data. | The program exited normally with status 0. |

## What this demonstrates

The call's return address and the saved `EBP` are separate stack entries. `EBP` provides stable offsets for the local variables while `ESP` moves to reserve and release their space. The function cleans up in reverse order: discard locals, restore `EBP`, then `ret` consumes the return address.

**Run observation:** Running the existing `./04` executable printed no output and exited with status 0.
